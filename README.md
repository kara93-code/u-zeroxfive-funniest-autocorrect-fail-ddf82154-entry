A program that writes one funny autocorrect fail to /output/entry.txt: a romantic "can't wait to see you tonight" becomes "can't wait to sue you tonight", and the date shows up with a lawyer instead of wine.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
